# Informe de Entrega

## 1. Resumen
Se implemento una aplicacion en Java Swing basada en MVC para gestionar eventos e invitados.

## 2. Requerimientos cumplidos
- Registro de nuevo evento.
- Listado de eventos.
- Eliminacion de uno o varios eventos.
- Registro de invitados asociados a eventos.
- Uso de componentes Swing.
- Estructura MVC.
